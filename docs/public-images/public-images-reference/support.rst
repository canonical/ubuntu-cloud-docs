Support options for Ubuntu cloud images
========================================

Launchpad bugs
--------------
`Launchpad's cloud-images project`_ is not a support channel, but it is a good place to find
technical information and report issues with Ubuntu cloud images. The Canonical Public Cloud (CPC) 
team will actively triage issues reported here. You can browse `reported bugs`_ to see if an issue
has already been raised before filing a new one.

Ubuntu documentation
---------------------
The following official Ubuntu documentation resources are useful when working with public images:

* `Find cloud images`_ - information about the different Ubuntu cloud image offerings.
* `Ubuntu tutorials`_ - broader tutorials relating to Ubuntu, many of which focus on cloud images,
  especially those running on OpenStack.
* `Ubuntu in the public cloud`_ - an overview of Ubuntu in public cloud environments generally.
* `Release cycle`_ - details on release lifecycles and support timelines for Ubuntu releases.

Ask Ubuntu
----------
Community-driven support is available through `Ask Ubuntu`_ on Stack Exchange and the
`Ubuntu Discourse`_ forum. These are useful for troubleshooting help, sharing configuration
tips, and getting advice from other Ubuntu users and Canonical community members, though
neither is a guaranteed or SLA-backed support channel.

Ubuntu Pro
----------
Ubuntu cloud images come with ``ubuntu-pro-client`` pre-installed. Purchasing an
`Ubuntu Pro`_ subscription grants entitlement to all Pro features. Technical support is
available as an add-on feature, and requires purchasing 'Ubuntu Pro + support'.

* `Ubuntu Pro overview`_ - what Pro includes, such as ESM, Livepatch and compliance tooling.
* `Ubuntu Pro pricing and support levels`_ - subscription tiers and the support add-on.
* `Ubuntu Pro Client documentation`_ - details on the ``ubuntu-pro-client`` package pre-installed on cloud images.
